Learning outcomes: create strings, create and manipulate lists, and create and access tuples.

Strings & Slicing

Immutable Character Sequences

Strings are sequences of characters enclosed in single ('...') or double ("...") quotes. They are immutable (cannot be altered once created).

  • Positive indexing starts from 0 left-to-right.
  • Negative indexing starts from -1 (last character) right-to-left.
  • Slicing [start:end] extracts substrings; out-of-range index raises IndexError.
str = "CODESYNC"
print(str[0:8])    # full string
print(str[0:4])    # first 4 chars
print(str[4:8])    # last 4 chars
print(str[-1])     # last char
print(str[-2:])    # last 2 chars
print(str[-6:-2])  # negative slice
Output: CODESYNC CODE SYNC C NC DESY
Lists
Ordered & Mutable

Defined inside square brackets []. Can hold mixed types (int, float, str, bool) and nested lists.

Key ops: len(), sort(), + (concatenation), sum(), append(), insert(), remove(), pop(), del. 

fruits = ["apple", "banana", "cherry"]
fruits[1] = "orange"
fruits.append("kiwi")
popped = fruits.pop()
print(fruits, popped)
['apple', 'orange', 'cherry'] kiwi
Tuples
Ordered & Immutable

Defined by enclosing comma-separated elements in parentheses (). Elements cannot be changed, added, or removed after creation.

Supports zero-based indexing, negative indexing, slicing, and nested tuples. 

tuple2 = ("apple", "banana", "cherry")
print(tuple2[0])
print(tuple2[-1])
print(tuple2[1:3])
apple cherry ('banana', 'cherry')
Textbook Programs

Average Marks (Lists) & Menu (Tuples)

Code Tip: del is a statement that deletes an object or reference, while pop() is a method that removes and returns a specific item from a list or dictionary.

Watch out for the common hurdle of mixing up square brackets [] for lists and parentheses () for tuples. 

subjects = ["Math", "Science", "History", "English"]
marks = [85, 90, 75, 80]
total_marks = sum(marks)
average_marks = total_marks / len(marks)

Python — Libraries (Pandas, Matplotlib & NumPy)

Learning outcomes: understand libraries, visualize data with Matplotlib, manipulate data with Pandas, and compute numerically with NumPy.

Data Manipulation

Pandas Library

Used to organize and analyze tabular data via DataFrame. Dictionary keys become column names and list values become column entries. 

import pandas as pd

detail = {
    'Name': ['Ramesh', 'Karan', 'Ruby'],
    'Age': ['17', '23', '13']
}
df = pd.DataFrame(detail)
print(df)
print(df.shape)
print(df.columns)
Name Age 0 Ramesh 17 1 Karan 23 2 Ruby 13 Shape: (3, 2) | Cols: ['Name', 'Age']
Data Visualization

Matplotlib Library

Enables plotting line graphs, bar charts, scatter plots, and pie charts effortlessly using matplotlib.pyplot (typically imported as plt). 

import matplotlib.pyplot as plt

months = ["Jan", "Feb", "Mar", "Apr", "May", "Jun"]
grades = [85, 90, 88, 92, 95, 89]

plt.plot(months, grades)
plt.title("Monthly Grades")
plt.show()
Chart Types: Line plot • Bar chart • Scatter • Pie chart
Numerical Python

NumPy Library

Open-source library for fast numerical computation, multi-dimensional arrays, and matrices in data science and machine learning. 

import numpy as np

num = [1, 2, 3, 4, 5]
num_array = np.array(num)
s = np.sum(num_array)
print(s)
Output: 15
